# David Santos — portfolio

Personal site: applied ML, robotics and production ML systems.
Live at https://hsantos10.github.io/

Built with React, Vite, Tailwind CSS 4 and shadcn/ui.

- Edit text in `src/content.ts`, layout in `src/App.tsx`, images in `public/img/`.
- `npm run dev` for a local server, `npm run build` for the static `dist/` folder.
- Every push to `main` builds and deploys through `.github/workflows/deploy.yml`.
